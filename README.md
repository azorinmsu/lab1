# Лабораторная работа №1. Платёжный процессор

Lab1 модуль списывает, отменяет и начисляет платежи.

`PaymentProcessor` зависит от `UserDatabase` (Spring Data JPA, Hibernate) и `BankSmsGateway`. Контрагент ищется по ИНН и КПП. Шлюз дополняет сообщение тестовым маркером, сериализует его в JSON и делает POST на фейковый эндпоинт `/api/sms/confirm`. 

Проверки входных данных:

- ИП: ИНН 12 символов, КПП пустой
- ЮЛ: ИНН 10 символов, КПП 9 символов
- наименование номенклатуры или услуги: от 1 до 100 символов
- назначение содержит НДС в формате `НДС %15`

Нужно написать модульные, интеграционные тесты на класс PaymentProcessor. Для интеграционных тестов нужно сделать мок для FakeSmsEndpoint. 
Для модульных тестов использовать JUnit + Mockito
На PaymentValidator должны быть написан рандомизированные тесты.  Рандомизированные надо написать на jqwik.

В реализации специально оставлены 5 дефектов с `NullPointerException` для разбора на лабораторной. Необходимо с помощью тестов их отловить.
